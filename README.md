# DrasTec – Tienda online

Web estática (un solo `index.html`) de DRASTEC IMPORT S.A.C., publicada con GitHub Pages.

- **Productos y precios:** se cargan desde la hoja de Google "DrasTec – Productos de la web". Para que funcione, la hoja debe estar compartida como "Cualquier persona con el enlace: lector". Si no carga, la web usa la lista de respaldo que viene dentro de `index.html`.
- **Imágenes:** carpeta `img/`.
- **Pedidos:** se confirman por WhatsApp (+51 958 842 548). Pagos por transferencia, Yape/Plin o pago de servicios.
- **Páginas legales:** Términos, Privacidad, Envíos, Preguntas frecuentes y Libro de Reclamaciones (rutas `#terminos`, `#privacidad`, `#envios`, `#preguntas`, `#reclamaciones`).
